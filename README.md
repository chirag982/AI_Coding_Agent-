# Autonomous Coding Agent

A minimal AI agent that writes Python code, tests it against a real test suite, and self-corrects until the tests pass — built from scratch with a plain function-calling loop (no LangChain/CrewAI).

## How it works

Given a task, the agent:
1. Writes a solution using `write_file`
2. Checks it using `run_tests` (pytest)
3. If tests fail, reads the failure output and rewrites the solution
4. Repeats until all tests pass or a max iteration limit is hit

This is a **Brain → Hands → Eyes → Loop** pattern — the model decides what to do, tools execute real actions, results are fed back, and it repeats autonomously with no human in the loop.

## Tech stack

- Python
- Hugging Face `InferenceClient` (`google/gemma-4-31B-it`)
- pytest
- `python-dotenv`

## Setup

```bash
pip install huggingface_hub python-dotenv pytest
```

Create a `.env` file in the project root:
```
API_token=your_huggingface_api_key
```

## Usage

Write your test cases by hand first — this is intentional, so verification stays independent of the model that writes the solution:

```
workspace/test_solution.py
```

Then run:
```bash
python coding_agent.py
```
Enter a task when prompted. The agent will generate a solution, test it, and iterate automatically.

## Project structure

```
coding_agent.py           # the agent itself
workspace/
  ├── test_solution.py    # hand-written, fixed test cases (ground truth)
  └── solution.py         # generated by the agent
```

## Known limitations

- Correctness is only as good as the hand-written test cases — passing tests is evidence of correctness, not proof
- Conversation history grows every iteration and is resent in full each time (no summarization/trimming yet)
- Single file, single task per run — no multi-file or cross-file context
